Build the operations dashboard for Harbour Cycles, the bike-share scheme in Bristol: 1,200 bikes, 400 of them electric, across 180 docking stations. The operations team keeps it open through the day to see which stations are empty or full, which e-bikes have a low battery, which bikes are reported broken, and where the four rebalancing vans are. Audience: the shift lead at the depot on a desktop monitor, and van drivers checking it on their phones. Primary action: assign a van to a rebalancing job. Use realistic sample data in the page; there is no backend. Plain HTML, CSS and JavaScript in one folder, no build step, no external images (you may use web fonts).
