Build a single-page marketing site for Heapwise, a pytest plugin that records the peak memory of every test and flags each test whose peak grew against the main branch, so a team finds the leaking test before the CI runner is killed for running out of memory. The plugin is free and open source; a paid hosted service keeps the history across branches and comments on pull requests. Audience: Python developers and platform engineers who look after test suites of several thousand tests. Primary action: install the plugin. Plain HTML, CSS and JavaScript in one folder, no build step, no external images (you may use web fonts).
